# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | Lists everything in the currect directory. This includes files and directories|
|     cd directory_name       | Navigates to the directory_name |
|     cd ..                   | This moves you one level up in the directory |
|     cd -                    | Goes back to the previous directory  |
|     mkdir directory_name    | This makes a new empty directory with given directory_name |
|     touch filename          | creates a new empty file |
|     git status              | Shows the current status of your repository including what is staged synced up |
|     git add -A              | git add tells git that you have changes you would like to save. -A is a shorthand for all|
|     git commit -m ""        | puts everything into a 'commit' which is basically a save point you can return to|
|     git push                | Sends the changes to the GitHub server where it is stored |
|     git pull                | Pulls changes that had been made to the version saved elsewhere such as in a main repository |
